# Produto comercial

As definições em Configurações guardam a identidade da instituição, URL do logótipo, cor principal, marca de água e rodapé para relatórios/cartas. Estes valores ficam no API remota e podem ser migrados directamente para `organization_settings` no Supabase.

Antes de operação financeira real, validar MFA, recuperação de conta, RLS, cifragem de backups, reconciliação bancária, integrações com operadores e revisão jurídica dos contratos e mapas regulamentares.
